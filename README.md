# HomeoRemedyTest для Windows

**Приложение для тестирования знаний по гомеопатии**

HomeoRemedyTest помогает студентам и практикующим гомеопатам эффективно готовиться к экзаменам и проверять свои знания.

---

## ✨ Возможности

- ✅ **Добавление карточек** с вопросами, ответами и объяснениями
- ✅ **Два режима просмотра**: классическая сетка и интерактивная стопка карточек
- ✅ **Умные фильтры** по темам, сложности и версиям
- ✅ **Поиск** по всем карточкам
- ✅ **Импорт/экспорт** в Excel для обмена вопросами
- ✅ **Синхронизация** с Яндекс.Диском для доступа с разных устройств
- ✅ **Бэкапы** данных

## 🚀 Быстрый старт на Windows

### Вариант 1: Готовый установщик (Рекомендуется)

1. **Скачайте установщик** `HomeoRemedyTest-Setup.exe` из раздела [Releases](https://github.com/zerocreator/HomeoRemedyTestWindows/releases)
2. **Запустите установщик** от имени администратора
3. **Следуйте инструкциям** мастера установки
4. **Запустите приложение** из меню Пуск или с рабочего стола

Приложение автоматически откроется в вашем браузере по адресу: `http://localhost:5001`

### Вариант 2: Сборка из исходного кода

Если вы хотите собрать приложение самостоятельно:

#### Требования:
- **Windows 10/11** (64-бит)
- **Python 3.10+** - https://www.python.org/downloads/
- **Git** (опционально) - https://git-scm.com/download/win

#### Инструкция:

```bash
# Клонируйте репозиторий
git clone https://github.com/zerocreator/HomeoRemedyTestWindows.git

# Перейдите в папку проекта
cd HomeoRemedyTestWindows\win_installer

# Запустите скрипт сборки
build.bat
```

После сборки executable файл будет находиться в: `dist\HomeoRemedyTest\HomeoRemedyTest.exe`

### Вариант 3: Онлайн версия

Посетите: https://homeoremedytest.vercel.app

## 🛠️ Создание Windows-установщика

Для создания полноценного `.exe` установщика:

1. **Установите Inno Setup 6**: https://jrsoftware.org/isdl.php#stable

2. **Запустите скрипт создания установщика**:
   ```bash
   cd win_installer
   build_installer.bat
   ```

3. **Установщик будет создан** в папке: `Output\HomeoRemedyTest-Setup.exe`

Подробная инструкция: [win_installer/BUILD_GUIDE.md](win_installer/BUILD_GUIDE.md)

## ⚙️ Настройка

### Переменные окружения (.env)

Создайте файл `.env` в корневой папке:

```env
# Настройки приложения
SECRET_KEY=your-secret-key-here

# Хранилище данных
STORAGE_MODE=local  # local, yandex, или hybrid

# Яндекс.Диск (опционально)
YANDEX_DISK_TOKEN=your-yandex-token
```
