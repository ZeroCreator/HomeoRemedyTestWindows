# HomeoRemedyTest - Установка на Windows

## 📋 Системные требования

- **Операционная система**: Windows 10/11 (64-бит)
- **Память**: минимум 2 ГБ ОЗУ
- **Место на диске**: ~200 МБ

---

## 🚀 Быстрый старт

### Вариант 1: Готовый установщик (Рекомендуется)

1. **Скачайте установщик**: `HomeoRemedyTest-Setup.exe`
2. **Запустите установщик** от имени администратора
3. **Следуйте инструкциям** мастера установки
4. **Запустите приложение** из меню Пуск или с рабочего стола

### Вариант 2: Сборка из исходного кода

Если вы хотите собрать приложение самостоятельно:

#### Шаг 1: Установка Python

1. Скачайте Python 3.10 или выше с https://www.python.org/downloads/
2. При установке **обязательно отметьте** галочку "Add Python to PATH"
3. Завершите установку

#### Шаг 2: Установка Git (опционально)

Скачайте и установите Git с https://git-scm.com/download/win

#### Шаг 3: Клонирование репозитория

```bash
git clone https://github.com/zerocreator/HomeoRemedyTest.git
cd HomeoRemedyTest
```

Или скачайте ZIP-архив и распакуйте его.

#### Шаг 4: Сборка приложения

Откройте командную строку (cmd) или PowerShell в папке проекта:

```bash
# Перейдите в папку win_installer
cd win_installer

# Запустите скрипт сборки
build.bat
```

Скрипт автоматически:
- Создаст виртуальное окружение
- Установит все зависимости
- Соберёт executable файл с помощью PyInstaller

После успешной сборки executable файл будет находиться в папке: `dist\HomeoRemedyTest\HomeoRemedyTest.exe`

#### Шаг 5: Создание установщика (опционально)

Для создания полноценного установщика Windows:

1. Установите **Inno Setup**: https://jrsoftware.org/isdl.php#stable
2. Запустите скрипт:
   ```bash
   build_installer.bat
   ```
3. Установщик будет создан в папке: `Output\HomeoRemedyTest-Setup.exe`

## 🔧 Настройка приложения

### Переменные окружения (.env)

Создайте файл `.env` в корневой папке проекта:

```env
# Настройки приложения
SECRET_KEY=your-secret-key-here
FLASK_ENV=production

# Хранилище данных
STORAGE_MODE=local  # local, yandex, или hybrid
LOCAL_DATA_PATH=data/test_cards.json

# Яндекс.Диск (опционально)
YANDEX_DISK_TOKEN=your-yandex-token
YANDEX_DISK_PATH=HomeoRemedyTest/data/test_cards.json

# Бэкапы
MAX_BACKUPS=50
BACKUP_ON_START=false
```

## 🎯 Использование

### Запуск готового приложения

1. **Дважды кликните** на `HomeoRemedyTest.exe`
2. Приложение автоматически откроется в браузере по умолчанию
3. Для остановки закройте окно командной строки

### Запуск через ярлык

После установки установщика:
- В меню Пуск появится ярлык "HomeoRemedyTest"
- Опционально создаётся ярлык на рабочем столе

### Доступ к приложению

Приложение открывается в браузере по адресу: `http://localhost:5001`

## 🐛 Решение проблем

### Приложение не запускается

1. Убедитесь, что установлен Python 3.10+
2. Проверьте, что все зависимости установлены:
   ```bash
   pip install -r requirements.txt
   ```

### Ошибка при сборке

1. Очистите предыдущие сборки:
   ```bash
   rmdir /s /q build dist
   ```
2. Запустите сборку заново:
   ```bash
   build.bat
   ```

### Порт занят

Если порт 5001 занят, приложение автоматически найдёт свободный порт.

### Проблемы с кодировкой

В Windows может потребоваться изменить кодировку:
```bash
chcp 65001
```
